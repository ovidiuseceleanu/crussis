# Crussis Avinox — catalog Bikeverse

Catalog de biciclete Crussis cu motor Avinox, pentru import în Bikeverse.

## Import (Alex)

- Fișier: **`crussis-avinox-bikeverse-v2.xlsx`** (503 variante, 106 produse)
- Instrucțiuni: **`CRUSSIS-AVINOX-IMPORT.md`**
- Pozele sunt locale, în folderul `Crussis Avinox images/`. Nu sunt în repo (1,8 GB).

Fișierul vechi `crussis-avinox-bikeverse.xlsx` nu se importă.
